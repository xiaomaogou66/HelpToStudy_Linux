# 📖 使用说明（一次性配置 5 分钟，之后每次学习 3 步）

## 0. 打开 Claudian（AI 入口，已装好）

1. 打开 Obsidian，右侧边栏找到 **Claudian** 图标（对话面板）。
2. 运行过「环境配置.sh」后，本机已装好 **Claude Code**；Claudian 里可在设置中选择后端（本机 Codex 或 Claude Code）。
3. 在输入框输入 `/` 即可看到本库的 5 条流程命令，点一下就调用：

| 命令 | 用途 |
| --- | --- |
| `/拆书 <文件>` | 导入教材，按章节拆分并生成全书大纲 |
| `/新主题-拆解与计划 <主题名>` | 五级水平拆解 + 二八定律 10 次学习计划，一键写入主题笔记 |
| `/测试我 <主题名>` | 十问考官测试，记录分数和薄弱点 |
| `/速查表 <主题名>` | 生成一页速查表（每次开课前 5 分钟复习） |
| `/学案 <章节> <主题>` | 阅读指定章节，一次生成"学案 + Session 记录"整合文件 |
| `/更新进度 <主题名>` | 读完 Session 记录，自动更新主题进度/级别/薄弱点 |

> [!tip] 省钱与后端选择
> - 默认用本机 Codex，不额外花钱。
> - 想用 DeepSeek（更便宜）：需安装 Claude Code CLI 并在 Claudian 设置里
>   启用 Claude 提供方、配置 Anthropic 兼容端点；或用 `/拆书` 之外
>   的成本控制习惯：每次只 @ 当前主题笔记，不给 AI 整个库。
> - 想让 AI 记住进度：**笔记就是记忆**。AI 只管当下，进度永远写在主题主页里。

## 1. 新建一个学习主题

- 按 `Ctrl+Shift+N`（或 `Ctrl+P` → 「➕ 新建学习主题」），输入主题名。
- 自动在 `03-学习主题/<主题名>/` 下生成主页笔记并打开。
- 填好主页 frontmatter 的 `topic`，把标题改成 `学习主题：<主题名>`。

## 2. 拆书（Step 1：解决教材超过上下文限制）

> 教材几十万到几百万字，AI 一次读不完。先拆成"一章一个文件"再学。

1. 双击 `_工具/拆书.sh`（或在终端运行），选择 / 拖入教材 **PDF**。
2. 工具调用 MinerU 云端识别（公式转 LaTeX，每日免费 1000 页），
   再按章节标题切分，完成后生成：
- `04-教材分块/<书名>/章节XXX-*.md`：一章一个文件的分块笔记
- `04-教材分块/<书名>/01-全书大纲.md`：**全书章节大纲 + 进度勾选清单**
3. 首次使用先运行一次 `_工具/设置MinerU令牌.sh` 保存 Token。
   想调整拆分不耗额度：直接把 `00-MinerU解析全文.md` 交给
   `_工具/拆书.sh`（自动识别为全文重切分，不消耗额度）。

> Linux 版只保留 MinerU 拆书：教材请提供 **PDF**（扫描版 / 数学书均可）；
> EPUB / Word 不在支持范围。

也可以在 Claudian 输入 `/拆书`，让 AI 帮你判断用哪种方式并执行。

## 3. 一键生成水平拆解 + 学习计划（Step 2 + Step 3 已合并）

1. 打开主题主页笔记，在 Claudian 输入：
   `/新主题-拆解与计划 <主题名>`
2. AI 自动完成两件事并写入笔记：
   - **五级水平拆解**：完全初学者 → 基本理解 → 实际使用者 → 问题解决者
     → 自信实践者（每级含概念、里程碑、练习、常见错误、自检题）
   - **二八定律学习计划**：20% 核心概念 + 10 个 Session（每 Session 2 小时，
     含目标、关键概念、练习、免费资源、复习题）+ 最终项目
3. 结果直接保存：拆解写入主页「水平拆解」区块，计划存为 `学习计划.md`。

> 如果这本书已拆好，先 @ 它的 `01-全书大纲.md` 再运行命令，计划会更贴合教材。

## 4. 学习与记录（每次 2 小时）

1. 每次学习前：`Ctrl+P` → 「📝 新建 Session 记录」，填好主题、次数、日期。
2. 学习时把笔记写进 Session 记录；开课前先看 `速查表.md`（5 分钟复习）。
3. 学完后在 Claudian 输入 `/更新进度 <主题名>`：
   AI 自动读 Session 记录，更新主页的进度 %、当前级别、状态和薄弱点，
   还能帮你勾选 `01-全书大纲.md` 里学完的章节。

## 5. 让 AI 考我（Step 4）

- 在 Claudian 输入 `/测试我 <主题名>`。
- AI 一次只问一个问题、逐题打分、指出缺口、最后给复习计划；
  结果自动存入 `测试记录.md` 并更新「薄弱点」。

## 6. 一页速查表（Step 5：每次开课前 5 分钟）

- 在 Claudian 输入 `/速查表 <主题名>`，自动生成 `速查表.md`。
- 之后每次学习/考试前，先花 5 分钟扫一遍它。

## 常见问题

**Q：AI 总是忘了我学到哪？**
A：每次对话前打开主题主页并 @ 它。进度永远写在笔记里，AI 只负责读和写。

**Q：书太厚，大纲还是太多？**
A：学不完就拆前几章先学；`01-全书大纲.md` 里勾掉学完的章节，
剩下的就是"还没学"清单。

**Q：想让 AI 用 DeepSeek 更省钱？**
A：在 Claudian 设置里启用 Claude 提供方并安装 Claude Code CLI，
再配置 Anthropic 兼容的 DeepSeek 端点（需自行确认端点可用性）。
不配置时，默认 Codex 后端即可直接使用。

**Q：我用的 niri（无桌面环境），怎么启动拆书？**
A：终端运行 `_工具/拆书.sh` 即可；安装库时已注册应用启动器，
也可从 fuzzel / rofi 等启动器搜索「拆书（MinerU）」。
目录/文件选择由 zenity 提供（环境配置.sh 会自动安装 zenity、xdg-utils）。

**Q：拆书卡在「上传解析中」反复重试，报 `context deadline exceeded`？**
A：那是扫描版 PDF 单份体积太大（比如 200 页 / 127 MB），上行没传完就被工具的超时掐断。
现在脚本会自动处理：先用 Ghostscript 把扫描页降到 200 DPI（191 MB → 63 MB，
识别精度不受影响，结果缓存在 `_工具/.mineru_cache/`，同一本书重跑不压第二次），
再按「≤200 页 **且** ≤25 MB」分块上传，单份上传超时还会自动对半切小重传。
网络仍慢就再调小（第二个参数会透传）：
`_工具/拆书.sh 某本书.pdf --mineru-chunk-mb 8`；
不想耗额度先看分块计划：`_工具/拆书.sh 某本书.pdf --mineru-dry-run`；
想保留 300 DPI 原件直传：`--mineru-dpi 0 --mineru-chunk-pages 40`。

**Q：每章标题是装饰字体（如《现代西班牙语》的 UNIDAD 第X课），整本书只认出 3 章？**
A：现在**默认就会自动纠正**（`--chapter-end-pattern auto`）：先从正文里挖
「每章都出现、且只出现一次」的小节（间隔还要求均匀），拿在每章最靠后的那个
（如「作业 (Trabajos de casa)」）当收尾锚点，章界 = 锚点之后的下一个章名行/
章首小节（如「课文 TEXTOS」）；只有比通用识别切出更多章时才采用，
切完还会校验每章字数。《现代西班牙语》两册这样就能正确切出 16 课。
想自己指定：`--chapter-end-pattern '习题\s*\(Ejercicios'`，必要时再配
`--chapter-title-pattern`（章起点特征）与 `--chapter-start-pattern`（第一章起点）；
不想要这套策略：`--chapter-end-pattern off`。重切不耗额度：
`_工具/拆书.sh "04-教材分块/<书名>/00-MinerU解析全文.md"`
